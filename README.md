# BMW Car Sales Dashboard

An interactive dashboard built with Streamlit to visualize BMW car sales trends by year, model, and region using Kaggle’s BMW dataset.

## Features
- Interactive filters (Year, Model, Region)
- Line chart for sales trends
- Bar chart for top models
- Pie chart for regional distribution
- KPIs for total sales

## Dataset
Source: Kaggle BMW Car Sales Dataset  
Columns: Year, Model, Region, Sales
